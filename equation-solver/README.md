# Решатель уравнений

Небольшое приложение на Python для решения линейных и квадратных уравнений с одной переменной. Показывает корни, дискриминант для квадратного уравнения и график на координатной плоскости.

## Запуск

Понадобятся Python 3.10 или новее и современный браузер. Из папки проекта запустите программу.

```sh
python app.py
```

Откройте `http://127.0.0.1:8001/`. Если порт занят, выберите другой с помощью `python app.py --port 8011`. Для остановки нажмите `Ctrl+C` в терминале. Приложение работает локально и использует стандартную библиотеку Python.

## Примеры

| Уравнение | Результат |
| --- | --- |
| `x^2 - 5x + 6 = 0` | Два корня, 2 и 3 |
| `x² - 4x + 4 = 0` | Один корень, 2 |
| `2x = 4` | Один корень, 2 |
| `x² + 1 = 0` | Два комплексных корня, ±i |
| `x + 2 = 2 + x` | Тождество, любое x |
| `x + 2 = x + 3` | Решений нет |

Записывайте обе части как суммы одночленов. Для квадрата подходят `x^2` и `x²`. Для коэффициента можно написать `1,5x` или `1.5*x`. Длина ввода до 160 символов, у чисел до семи цифр до разделителя и до шести после. Скобки, деление и степени выше второй выходят за пределы поддерживаемого формата.

Python переносит правую часть в левую и вычисляет корни через `Decimal`. Браузер рисует на Canvas функцию **y = левая часть − правая часть**. Корни на графике отмечены точками пересечения с осью x. Кнопки `−` и `+` меняют видимый диапазон по x, кнопка с процентом возвращает исходный масштаб.
