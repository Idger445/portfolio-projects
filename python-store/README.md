# Поле

Демонстрационный интернет-магазин канцелярских товаров. В витрине можно выбрать товары, изменить количество в корзине и оформить заказ, который сохранится в SQLite.

## Запуск

Требуется Python 3.10 или новее со стандартным модулем `sqlite3`. Откройте терминал в папке проекта.

```sh
python shop.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Сервер выводит фактический адрес при запуске. Остановить его можно сочетанием Ctrl+C.

Если порт занят или нужна отдельная база, укажите параметры.

```sh
python shop.py --port 8082 --db demo.sqlite3
```

## Как проверить

1. Добавьте в корзину блокнот «Мох» и карандаш «Графит».
2. Откройте корзину, измените количество блокнотов на два и нажмите «Обновить». Итог составит **74,50 BYN**.
3. Введите вымышленное имя и адрес `demo@example.com`, затем нажмите «Оформить демозаказ». Появится номер заказа, а корзина очистится.

Сервер принимает соединения только на локальном компьютере. Имя и адрес электронной почты сохраняются в файле SQLite, поэтому для проверки используйте вымышленные данные. Оплата, доставка и отправка писем отсутствуют.

## Реализация

- `shop.py` обрабатывает HTTP-запросы, формирует HTML и пересчитывает заказ по каталогу на сервере. Цены хранятся в целых копейках.
- Корзина хранится в cookie браузера. Сервер проверяет коды товаров, количество и данные формы. Каталог и оформление работают с обычными HTML-формами.
- При первом запуске создаётся `shop.sqlite3`. Данные заказа сохраняются в таблице `orders`, позиции с ценами на момент покупки — в `order_items`. Заказ и позиции записываются в одной транзакции. Повторная отправка той же формы не создаёт дубликат.
- `static/style.css` задаёт адаптивную сетку. Фотография коллекции сгенерирована для проекта с помощью OpenAI ImageGen. Все ресурсы загружаются локально.
