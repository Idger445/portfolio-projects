# Проекты для портфолио

Семь самостоятельных проектов на HTML/CSS, Python, C и C++. В каждой папке есть исходники и инструкция по запуску.

| Проект | Стек | Что можно попробовать |
| --- | --- | --- |
| [Зерно](coffee-landing/) | HTML, CSS | Перейти с главной на страницу меню или узнать, где находится кофейня и когда она работает. |
| [Свод](pricing-page/) | HTML, CSS | Сравнить месячные и годовые тарифы и открыть страницу частых вопросов. |
| [Трекер расходов](expense-tracker/) | Python, JSON | Добавить траты, отфильтровать их по категории и вывести итог за месяц. |
| [Решатель уравнений](equation-solver/) | Python, Canvas | Выбрать уравнение на странице примеров или ввести своё, найти корни и посмотреть график. |
| [Поле](python-store/) | Python, SQLite, HTML, CSS | Открыть каталог и карточки канцтоваров, собрать корзину и оформить демозаказ. |
| [Крестики-нолики](tic-tac-toe/) | C++17 | Сыграть вдвоём за одной клавиатурой. |
| [Записная книжка](contact-book/) | C11, TSV | Добавить, найти, отредактировать и удалить контакт. |

Статические страницы открываются из `dist/index.html`. Проекты на Python используют стандартную библиотеку. Для C и C++ команды сборки приведены в README каждого проекта.
