# Трекер расходов

Консольное приложение на Python для учёта повседневных расходов в BYN. Расходы сохраняются в JSON, а отчёт за месяц показывает суммы по категориям и общий итог.

## Запуск

Требуется Python 3.10 или новее. Откройте терминал в папке проекта.

```sh
python tracker.py --help
python tracker.py add 12,50 продукты --date 2026-11-02 --note "Обед"
python tracker.py add 3.80 транспорт --date 2026-11-02 --note "Метро"
python tracker.py add 8 продукты --date 2026-11-03
python tracker.py list --month 2026-11 --category продукты
python tracker.py summary 2026-11
```

В отчёте для этого примера будут такие строки.

```text
Расходы за 2026-11
продукты | 20,50 BYN
транспорт | 3,80 BYN
Всего | 24,30 BYN
```

## Команды

| Команда | Действие |
| --- | --- |
| `add СУММА КАТЕГОРИЯ [--date ДАТА] [--note ТЕКСТ]` | Добавляет расход. По умолчанию используется сегодняшняя дата. |
| `list [--month МЕСЯЦ] [--category КАТЕГОРИЯ]` | Показывает расходы от новых к старым. Фильтры можно сочетать. |
| `summary [МЕСЯЦ]` | Показывает расходы по категориям и общий итог. По умолчанию используется текущий месяц. |

Сумму можно указать с точкой или запятой и максимум двумя знаками после разделителя. Категории свободные, регистр при вводе игнорируется. Названия из нескольких слов указываются в кавычках, например `"дом и быт"`.

По умолчанию записи сохраняются в `expenses.json` рядом со скриптом. Для отдельного файла укажите `--file` перед командой, например `python tracker.py --file vacation.json summary 2026-11`. Приложение создаёт файл при первом добавлении. Соседний файл `.lock` используется для синхронизации записи между процессами.

## Реализация

- `argparse` разбирает аргументы командной строки и проверяет сумму, категорию, дату и месяц.
- Суммы хранятся целыми числами в копейках, поэтому сложение получается точным.
- Запись проходит через временный файл и атомарную замену JSON. При ошибке чтения добавление прерывается до записи.

Приложение использует стандартную библиотеку Python.
