# Записная книжка

Консольный менеджер контактов на C11. Контакт хранится в структуре `Contact`, а массив записей растёт через `realloc`. Программа умеет добавлять, искать, редактировать и удалять записи. Изменения сразу сохраняются в текстовом TSV-файле.

## Сборка и запуск

Из папки проекта, с GCC или Clang:

```sh
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o contact-book
./contact-book
```

В PowerShell с MinGW укажите имя `contact-book.exe` после `-o` и запустите `./contact-book.exe`. В Developer PowerShell для Visual Studio можно собрать командой `cl /std:c11 /W4 /D_CRT_SECURE_NO_WARNINGS main.c /Fe:contact-book.exe`.

## Меню

| Пункт | Действие |
| --- | --- |
| `1` | Показать список с номерами контактов |
| `2` | Добавить имя и телефон, при желании указать электронную почту |
| `3` | Найти подстроку в любом из трёх полей |
| `4` | Ввести номер контакта и заполнить его поля заново |
| `5` | Удалить контакт по номеру |
| `0` | Выйти из программы |

Поиск игнорирует регистр латинских букв ASCII. Для кириллицы и других символов используйте регистр из самой записи. Поля ограничены 96, 48 и 128 байтами соответственно. Для кириллицы используйте терминал с UTF-8.

## Файл данных

По умолчанию используется `contacts.tsv` в текущей папке. Другой путь можно передать при запуске, например `./contact-book demo.tsv`. Первая строка содержит `contact-book-v1`, следующие строки содержат имя, телефон и электронную почту через табуляцию. При ошибке разбора программа сообщает номер строки с повреждённой записью и оставляет исходный файл на месте.

При сохранении программа записывает `<файл>.tmp` рядом с основным файлом и заменяет основной файл после успешной записи. Файл `<файл>.lock` ограничивает доступ к книге одной копией программы. Если процесс аварийно завершился и оставил временные файлы, убедитесь, что копий программы больше нет, проверьте данные в `.tmp` и удалите оставшиеся `.lock` и `.tmp` перед следующим запуском.
