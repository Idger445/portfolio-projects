# Зерно

Адаптивный трёхстраничный сайт вымышленной кофейни в Минске.

## Запуск

Откройте `dist/index.html` в браузере. Сборка и подключение к интернету не нужны.

## Страницы

- [`dist/index.html`](dist/index.html) — знакомство с кофейней и фото.
- [`dist/menu.html`](dist/menu.html) — напитки, выпечка, объёмы и цены.
- [`dist/visit.html`](dist/visit.html) — район, часы работы и детали визита.

## Что показывает проект

- Семантический HTML, навигация между страницами с отметкой текущего раздела и ссылка для перехода к основному содержимому с клавиатуры.
- CSS Grid для первого экрана и меню, Flexbox для навигации и строк с ценами.
- Медиазапросы для одноколоночной раскладки и компактного меню на узких экранах.
- Локальное фото для первого экрана создано через ImageGen.
