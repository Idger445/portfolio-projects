# Зерно

Адаптивный лендинг вымышленной кофейни в Минске. На странице есть меню с ценами, район и часы работы.

## Запуск

Откройте `dist/index.html` в браузере. Сборка и подключение к интернету не нужны.

## Что показывает проект

- Семантический HTML, якорная навигация и ссылка для перехода к основному содержимому с клавиатуры.
- CSS Grid для первого экрана и меню, Flexbox для навигации и строк с ценами.
- Медиазапросы для одноколоночной раскладки и компактного меню на узких экранах.
- Локальное фото для первого экрана создано через ImageGen.
