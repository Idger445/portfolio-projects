# Крестики-нолики

Консольная игра на C++17 для двух игроков за одной клавиатурой. Класс `Game` хранит поле в `std::array`, проверяет ходы и определяет победителя по восьми линиям. Ввод и вывод обрабатываются в `main`.

## Сборка и запуск

Из папки проекта, с GCC или Clang:

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o tic-tac-toe
./tic-tac-toe
```

В PowerShell с MinGW укажите имя `tic-tac-toe.exe` после `-o` и запустите `./tic-tac-toe.exe`. В Developer PowerShell для Visual Studio можно собрать командой `cl /std:c++17 /EHsc /W4 main.cpp /Fe:tic-tac-toe.exe`.

## Как играть

- Введите номер свободной клетки от `1` до `9` и нажмите Enter. Первым ходит `X`.
- После победы или ничьей введите `y`, чтобы сыграть снова, или `n`, чтобы завершить игру.
- Во время партии для выхода введите `q`.

Ходы `1, 4, 2, 5, 3` дают победу `X` по верхней строке. Чтобы проверить ничью, начните новую партию и введите `1, 2, 3, 5, 4, 6, 8, 7, 9`. Каждый ход вводится с новой строки.
